# Hệ thống Quản lý Sinh viên
Hệ thống sử dụng Node.js/Express, MySQL, Nginx làm Reverse Proxy.

## Hướng dẫn chạy
1. Sao chép `.env.example` thành `.env` và điền mật khẩu.
2. Chạy lệnh: `docker compose up -d --build`
3. Truy cập:
   - Web App: https://localhost
   - phpMyAdmin: https://localhost/phpmyadmin/
